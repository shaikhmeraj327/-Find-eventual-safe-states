# -Find-eventual-safe-states

Given a directed graph with `V` vertices numbered from `0` to `V - 1` and directed edges represented as pairs `[u, v]`, return all **safe nodes**.

A node is safe if every path starting from it eventually ends at a terminal node (a node with no outgoing edges).
